Siteplan Project

Site Name

The site name is 'Ogden City Crafty Club'. This is the name that I chose because it is breif but descriptive. It includes the name and the area it serves. It describes the point and the relavant info.

Optional domain name: craftyclub-ogden.com

Site Purpose

This would describe the club, as well as showcase a few of the members and their specialties if someone is looking for help to learn a new skill.

Scenarios

When and where is the next meeting for the club?

If I don't already have a craft, what kinds of skills would I be able to learn?

Who are the teachers for these skills?

Color Schema

The main text color will be: #0B2129

The two secondary colors will be: #57C9BC and #F09413

Topography
